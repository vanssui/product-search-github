# Матрица функционального соответствия

Статус: ожидает выполнения интеграционных тестов после deployment тестового backend.

| Функция | Версия 51 | GitHub-версия | Результат | Комментарий |
|---|---|---|---|---|
| Получение активных строк | `getTasks` | `GET action=getTasks` | ожидает | та же фильтрация `Поиск` |
| Поиск по ID | клиентский | клиентский | unit test пройден/ожидает UI | без серверной записи |
| Поиск по WB-стикеру | клиентский | клиентский | unit test пройден/ожидает UI | поддержаны несколько стикеров |
| Сортировка MX | серверная | серверная | ожидает | зона → этаж → ряд → место → полка → ячейка |
| Взять задание | отсутствует | `takeTask` | ожидает | новое усиление, TTL 10 минут |
| Блокировка второй сессии | только first-write-wins | явный owner lock | ожидает | новое усиление |
| Найдено | `updateTask` | `completeTask` | ожидает | статус + ID сотрудника |
| Не найдено | `updateTask` | `completeTask` | ожидает | статус + ID сотрудника |
| Повторное завершение | `alreadyClosed` | `alreadyClosed` + idempotency | ожидает | усилено |
| Загрузка фото | Drive + ID в строке | Drive + ID в строке | ожидает | MIME/5 МБ/owner checks |
| Получение фото | base64 | base64 | ожидает | только тестовая папка |
| Освобождение | отсутствует | `releaseTask` | ожидает | новое усиление |
| Истечение TTL | отсутствует | 10 минут | ожидает | новое усиление |
| Две сессии | first-write-wins | explicit ownership | ожидает | интеграционный тест |
| Ошибка сети | failure handler | timeout/offline/no POST retry | unit/UI ожидает | черновик не очищается |
| Mobile 320 px | mobile layout | mobile-first 320 px | ожидает | browser QA после сборки |
| Polling | 150/300 секунд | 150/300 секунд | по коду | не выполняется при открытой карточке |
